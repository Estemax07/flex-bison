# Flex & Bison – Capítulo 1

Implementación de los ejemplos 1–5 y resolución de los ejercicios 1–6 del capítulo 1 del libro **Flex & Bison**.

Probado en **macOS (Apple Silicon / M2)** con Flex y Bison instalados por Homebrew.

---

## Estructura del proyecto

- `cap1/ex1` a `cap1/ex4`: ejemplos del libro (Flex)
- `cap1/ex5/base`: calculadora base (Flex + Bison)
- `cap1/ex5/ej1` a `cap1/ex5/ej6`: ejercicios incrementales sobre la calculadora

---

## Requisitos

### macOS (Apple Silicon)
Instalación recomendada (Homebrew):

```bash
brew install flex bison
